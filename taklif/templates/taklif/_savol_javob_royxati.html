{% trans "To'lovni qanday amalga oshiraman?" %}

{% blocktrans %}Avval taklifnomangizni bepul yaratib, uni to'liq ko'rib chiqasiz. Yoqsa, taklifnoma sahifasidagi "Yoqdi" tugmasini bosing — shu orqali sizni to'g'ridan-to'g'ri Telegram'dagi adminimiz bilan bog'laymiz va to'lov tafsilotlarini o'sha yerda kelishasiz. To'lov tasdiqlangach, taklifnomangiz faollashtiriladi.{% endblocktrans %}

{% trans "Ro'yxatdan o'tishim yoki parol o'ylab topishim kerakmi?" %}

{% blocktrans %}Yo'q. Hech qanday ro'yxatdan o'tish, email yoki parol talab qilinmaydi — dizaynni tanlab, ma'lumotlaringizni kiritasiz, xolos. "Taklifnomalarim" bo'limi orqali shu brauzeringizda yaratgan barcha taklifnomalaringizni istalgan vaqt qayta topishingiz mumkin.{% endblocktrans %}

{% trans "Ma'lumotlarda xato qilib qo'ysam, tuzata olamanmi?" %}

{% blocktrans %}Ha. Xuddi shu ism bilan formani qayta to'ldirsangiz, tizim avvalgi taklifnomangizni taniydi va uni yangilashni yoki alohida saqlashni so'raydi. Kattaroq o'zgarish yoki muammo bo'lsa, taklifnoma sahifasidagi "Yoqdi" tugmasi orqali to'g'ridan-to'g'ri adminimizga yozishingiz mumkin.{% endblocktrans %}

{% trans "Taklifnoma linki qachon tugaydi?" %}

{% trans "Avtomatik tugamaydi — to'y yoki marosim o'tib ketgandan keyin ham link ishlab turadi. Uni faolsizlantirish kerak bo'lsa, faqat qo'lda (admin panelidan) qilinadi." %}

{% trans "Mehmonlarim javobini (kelaman/kelolmayman) kuzatib borsam bo'ladimi?" %}

{% blocktrans %}Ha. Har bir taklifnomaning faqat sizga ko'rinadigan maxfiy statistika sahifasi bor — u yerda nechta kishi ko'rgani, kim "kelaman" yoki "kelolmayman" deb javob bergani va mehmonlarga bergan shaxsiy linklaringizni kim ko'rib-ko'rmaganini kuzatib borasiz. Havolasini "Taklifnomangiz tayyor!" sahifasida topasiz.{% endblocktrans %}

{% trans "Nechta rasm va qanday musiqa qo'sha olaman?" %}
