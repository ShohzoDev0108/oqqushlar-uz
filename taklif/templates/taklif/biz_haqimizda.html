{% trans "Biz haqimizda" %}

{% blocktrans %}Oqqushlar — to'y, fotiha, beshik to'yi va boshqa oilaviy marosimlar uchun raqamli taklifnomalar tayyorlaydigan xizmat. Bosma taklifnomadan farqli o'laroq, sizning taklifnomangiz oddiy havola bo'lib, uni Telegram yoki boshqa istalgan joyda ulashasiz — mehmon uni telefonida ochadi, manzilni xaritada ko'radi va "kelaman" deb javob beradi.{% endblocktrans %}

{% blocktrans %}Xizmatni o'zingiz boshqarasiz: dizaynni tanlaysiz, ma'lumotlarni to'ldirasiz va taklifnoma shu zahoti tayyor bo'ladi. Bizga yozib o'tirish, kutish yoki kelishuv shart emas — hammasi telefoningizda, bir necha daqiqada.{% endblocktrans %}

  • {% trans "Sakkiz tilda" %} {% blocktrans %}O'zbek, rus, ingliz, tojik, qozoq, qirg'iz, turkman va qoraqalpoq tillarida — mehmonlaringiz taklifnomani o'z tilida o'qiydi.{% endblocktrans %}
  • {% trans "Ro'yxatdan o'tish shart emas" %} {% blocktrans %}Email ham, parol ham so'ralmaydi. Yaratgan taklifnomalaringizni "Mening taklifnomalarim" bo'limidan istalgan vaqt topasiz.{% endblocktrans %}
  • {% trans "Har bir mehmonga shaxsiy havola" %} {% blocktrans %}Taklifnoma mehmonni ismi bilan kutib oladi, siz esa kim ko'rgani va kim javob berganini kuzatib borasiz.{% endblocktrans %}
  • {% trans "Avval ko'rasiz, keyin to'laysiz" %} {% blocktrans %}Taklifnomangizni bepul yaratib, to'liq ko'rib chiqasiz. To'lov — faqat yoqqanidan keyin.{% endblocktrans %}
